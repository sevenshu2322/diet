# diet
<h1>膳食管理，你的日常饮食管家。</h1>（Diet management, your daily food guide.）
<h2>它解决什么问题？</h2>
每天最让人头疼的问题不是"吃什么"，而是"吃什么才健康"。

想营养均衡，但懒得算配比；想吃得健康，但不知道具体该选哪些食物；健身的人要控碳水、盯蛋白，不健身的人也想吃得清爽不油腻——不同需求，同一个困境：不知道怎么吃才对。

这个工具就是为这个问题写的。

<h2>核心功能</h2>
<h3>1. 注重营养均衡</h3>
不是简单列个食谱，而是从营养搭配的角度出发，帮你把一顿饭该有的东西配齐。不用自己查表算数，工具会帮你把关。

<h3>2. 推荐食物，专治选择困难</h3>
不知道吃什么的时候，它会直接给你推荐。不是那种"多吃蔬菜水果"的空话，而是具体到可以照着选的食物建议，给你实实在在的启发。

<h3>3. 适用大多数人</h3>
不管你是：

健身人群：需要关注蛋白质、碳水、热量配比

不健身但想吃得健康的人：不想吃太重口，想吃得均衡舒服

都能在这个工具里找到适合自己的方案。它不挑人，只看你想不想吃得好一点。
<h2>适合谁用？</h2>
1.每天纠结"吃什么"的人

2.想吃得健康但不知道从哪下手的人

3.健身但不想每顿都自己算宏量营养素的人

4.对开源项目感兴趣、愿意提建议一起完善的人
