# 2026-10-04

## 用户反馈：蛋白质目标不合理
> 「久坐、轻度、中度的蛋白质不应该是一样的，而且高度和极高的应该为每公斤 1.6~2.2g」

确实是个真实缺陷：原 `calcAutoTarget` 只按 goal（cut/bulk 才上调到 1.2 g/kg）算蛋白质，
**完全没读活动量**，导致久坐 / 轻度 / 中度三档都是同一个 RNI（男 65 / 女 55 g）。

## 改法
1. 拆出新函数 `calcProteinTarget(pr, kcal)`，按 ACTIVITY 五档取 g/kg 区间，
   在区间内按 goal 取位（cut 0.85 / maintain 0.55 / bulk 0.90），乘参考体重。
2. `DRI.proteinAMDRHiByAct = [.20,.20,.22,.25,.28]`：蛋白供能比上限随活动量放宽，
   否则「高训练量 + 减脂」这种热量被压低的组合会被国标 20% 硬夹到远低于 1.6 g/kg。
3. 脂肪改为**双向**给碳水让路（原来只能抬不能压），否则蛋白放宽后碳水下破 50%。
4. `proteinRefWeight()`：BMI ≥ 28 用调整体重（理想体重 + 40% 超出部分），
   修掉「120kg/165cm + 极高 + 增肌 → 242g / 28% 供能比」的不现实结果。
5. 「我的目标」页新增「蛋白质按你的训练频率算」整段：列出五档区间、标出当前档、
   说明参考体重和供能比上限，AMDR 对照行的标签在放宽时改成「本档适用」。

## 校验
- 遍历「5 种体征 × 3 目标 × 5 活动量」= 60 组合：脂肪 20~30%、碳水 50~65%、三项合计 100%，零越界。
- 五档 g/kg 实测（男 70kg/175cm/30 岁 · 维持）：1.01 / 1.17 / 1.42 / 1.82 / 2.02。
- 纯函数测试 **249/249**（+26），DOM 冒烟 **432/432**（+16）。
- 旧断言里有 4 条按「1.2 g/kg」「= 65g」写死的，已改成新模型的表达式，没有直接删。
